Build requires .NET SDK, .NET Framework 4.7.2 targeting pack, and a local Valheim installation with BepInEx and Jotunn. Game assemblies are not distributed.

    dotnet build src/BossMagic.Test.csproj -c Release -p:GameDir="PATH_TO_ISOLATED_VALHEIM"

Package 0.13.1 contains plugin 0.13.0 unchanged; only the icon, cover and package metadata were updated. Multiplayer is experimental and still needs validation with multiple players on a dedicated server.
